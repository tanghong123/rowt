# block-domains.txt — domains refused instantly (no DNS, no dial).
#
# This is the "block" lane: an ad/telemetry sinkhole that runs BEFORE
# corp/escape/direct. It exists to stop the direct-lane retry storm — dead
# ad/tracker/telemetry hosts being retried in a tight loop — that spikes
# sing-box CPU.
#
# This hand list is ADDITIVE on top of the big geosite ad/tracker rule-set
# (thousands of domains), which `rowt fetch host` caches and rowt renders in
# automatically when present. Put your own additions here.
#
#   rowt block add <domain>     rowt block rm <domain>     rowt block list
#
# Matching is domain_suffix (HasSuffix), same as the escape/corp lists — so
# `360yield.com` also covers `ad.360yield.com`. One entry per line; # = comment.

# --- top offenders observed pegging the direct lane ---
