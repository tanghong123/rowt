# The watchdog's captive classifier (DESIGN.md §11). These pick the portal the
# tick sees through the environment rather than argv, which is why the matrix
# accepts leading VAR=VALUE tokens. Together they walk the decision table:
# clear / captive-by-body / captive-by-redirect / unknown-on-failure.
watch_tick_clear    mut  ROWT_CAPTIVE_URL=http://127.0.0.1:8099/success watch tick
watch_tick_portal   mut  ROWT_CAPTIVE_URL=http://127.0.0.1:8099/portal watch tick
watch_tick_redirect mut  ROWT_CAPTIVE_URL=http://127.0.0.1:8099/redirect watch tick
watch_tick_unknown  mut  ROWT_CAPTIVE_URL=http://127.0.0.1:9/x watch tick
# …and the same portal with the proxy actually on, which is what makes the tick
# take the drop branch rather than logging 'proxy already off'.
watch_tick_drop     mut  PARITY_SCENARIO=proxy-on ROWT_CAPTIVE_URL=http://127.0.0.1:8099/portal watch tick
# Mid-episode: state says captive, the portal now answers clear -> restore.
watch_tick_restore  mut  PARITY_SCENARIO=captive-episode ROWT_CAPTIVE_URL=http://127.0.0.1:8099/success watch tick
